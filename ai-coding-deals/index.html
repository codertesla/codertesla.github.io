收录什么

  • 精选优惠与返利 按「成本／能力比」排序的短名单，覆盖 Cursor、Claude Code、GitHub Copilot、Cline、OpenCode 等主流工具的实际报价与额度机制。
  • 零成本方案（$0 / BYOK） 用开源客户端搭配免费推理额度，组合出一套零月费的可用工作流，不依赖任何订阅。
  • Agentic IDE 比价 面向仓库级上下文索引、多文件重构与沙箱执行的编辑器，横向对比档位与配额上限。
  • 编辑器扩展 VS Code 与 JetBrains 插件的免费额度现状，包含已转为仅企业版、不再向个人开放的条目说明。
  • CLI 与终端 Agent 终端类编程代理的计费方式、额度窗口与超额后的降级行为。
  • 限时促销与学生优惠 时效性优惠单独成表，过期即剔除；.edu 学生包的申请条件与可用范围另列。
  • 决策矩阵与省钱准则 一张横向对比表，加上 7 条降低 token 开支的实操规则，用于在动手订阅前先算清账。

为什么可以照着买

标注 Verified 的条目，均与厂商官方文档逐项核对过，包括价格、额度窗口与模型 ID 这类容易记错的细节。

过期促销、暂停注册以及仅面向企业的工具会被移出精选短名单，但仍保留在对应分类表中，避免读者重复踩坑。

每月复核一次，页面数据以仓库内的核验日志为准。发现价格变动，可以直接提 PR 补充。
